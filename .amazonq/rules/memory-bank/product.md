# Nexivio Care Admin — Product Overview

## Purpose
Admin dashboard for the Nexivio Care platform — a healthcare/care services management system. Provides full CRUD control over all platform content and operations.

## Key Features
- **Bookings & Transport**: Manage service bookings and transport/vehicle bookings
- **Staff & Team**: Manage staff members and team profiles with images
- **Services**: Manage care services and other-services listings
- **Applications & Enrollments**: Handle user applications and training enrollments
- **Gallery & Banners**: Manage media content (images/videos)
- **Notices & Reviews**: Publish notices and moderate user reviews
- **Contacts**: View and manage contact form submissions
- **SMS**: Send SMS communications
- **Settings**: Platform configuration
- **Vehicle Registrations**: Manage registered vehicles for transport

## Target Users
Internal admin staff of Nexivio Care who manage day-to-day operations of the platform.

## Locale
Bilingual UI — Bengali (primary display) and English. Dates/times formatted for Bangladesh (Asia/Dhaka, bn-BD locale).

## Deployment
Deployed on Vercel. Runs on port 3001 in development. Connects to a separate backend API (`NEXT_PUBLIC_API_URL`).
